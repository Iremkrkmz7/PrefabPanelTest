# PrefabPanelTest

Unity editor tool denemesi: prefab override'larını listeleyen özel bir editor paneli.

## İçerik

- `Assets/Editor/PrefabOverridePanel.cs` — editor paneli
- `Assets/TestPanel.prefab` — test için örnek prefab
- `Assets/Scenes/SampleScene.unity` — örnek sahne

## Kurulum

1. Repoyu klonla.
2. Unity Hub → **Add** → proje klasörünü seç.
3. Unity sürümü: **2022.3.56f1**
